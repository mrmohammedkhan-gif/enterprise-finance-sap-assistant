\## Evidence-Safe CV Bullets



\- Built an end-to-end Enterprise SAP Finance AI Assistant portfolio project integrating Python, FastAPI, SAP-style finance logic, RAG and agentic workflow concepts across AP, AR, GL, tax, journals and month-end close.



\- Designed finance controls including posting-period validation, approval workflows, role-based access controls and AI guardrails to demonstrate how generative AI can operate within governed finance processes.



\- Developed REST API services for finance workflows including profit-and-loss analysis, vendor invoices, open items, company codes, journal entries and posting-period controls.



\- Applied retrieval and response evaluation concepts including Precision, Recall, Mean Reciprocal Rank (MRR) and nDCG to assess AI and retrieval quality.



\- Designed a layered enterprise architecture spanning finance users, API services, AI orchestration, finance-domain services, structured finance data, governance and observability.



\- Used Git and GitHub to manage the project through controlled module checkpoints, documentation and portfolio packaging.
